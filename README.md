# The Daily Chronicle — Text-Only Newsroom Investigation

Open `index.html` in a modern browser. The project is static and does not require a server, account, database, or build step.

## Files
- `index.html` — page structure
- `styles.css` — visual design
- `script.js` — baseline quiz, six newsroom cases, teaching debrief, final quiz, scoring, and CSV downloads

## Participant flow
1. Four baseline questions
2. Six text-only news investigations (headline, article blurb, expandable evidence notes)
3. Editor's debrief
4. Four matched-skill final questions
5. Results page with session-summary and trial-level CSV downloads

No photographs, AI-generated images, remote image links, or image assets are used. Google Fonts are optional; the page uses fallback system fonts if unavailable.

## Data
CSV files are generated locally in the participant's browser when the participant selects the download buttons. No participant data is sent to a server.
